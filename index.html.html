Sunna3

Maintenance Management Platform

We all know the frustration — you need a technician fast, but have no idea who to call or whether they're trustworthy. That gap is exactly what Sunna3 was built to close.

Sunna3 is a full-stack maintenance platform connecting tenants with qualified technicians through a transparent, structured process — from raising a ticket to payment and review.

We built a Data Analysis Dashboard with real-time charts & reports, and integrated AI models to guide tenants before ticket creation and to generate predictive maintenance alerts for registered devices.

TeleChat
Real-Time Communication

TeleChat goes beyond basic messaging. Built on SignalR for real-time bidirectional communication over WebSockets, it brings together features that apps like Telegram and WhatsApp offer — but missing from most .NET chat demos:

Video calls with live camera streams, voice-only calls for audio-focused sessions, and call recording so conversations aren't lost. The Angular frontend handles real-time state updates as connections open and close, while the .NET backend manages hub connections, call signaling, and session tracking with clean, typed TypeScript integration.

Questar
Exam & Certification Platform

Building a reliable online exam system is harder than it sounds — you need live session management, strict timing, fair auto-grading, and tamper-resistant certificates, all without a broken user experience.

Questar automates the full testing lifecycle: candidates enter a live exam session with enforced time limits, submit answers that are instantly graded by the system, receive a detailed result breakdown, and — if they pass — get a certificate issued automatically. Admins manage question banks, configure passing thresholds, and track performance across all candidates from a single dashboard.
